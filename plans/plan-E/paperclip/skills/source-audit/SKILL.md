# Public source audit

## Inputs
Original sponsor documents, candidate official filings and retrieval date. The baseline includes a 44-page DESC list and a 668-page Georgia public-disclosure PDF; the latter includes mixed CEII markings.

## Procedure
1. Record publisher, source URL/local path, hash, publication/retrieval dates, document version and page numbering convention. Inspect each proposed page range, including headers/footers, before marking it approved.
2. Quarantine CEII, redactions and conflicting public/confidential markings. Never upload unresolved pages to Gemini or display excerpts. A public URL alone is insufficient. Seek an unambiguously public alternative and ask the human source owner to resolve outstanding classification.
3. Inventory every candidate in the chosen source scope with an explicit disposition. Review the full DESC lists; for Georgia retain the approved table inventory denominator and identify the bounded border subset used for location work.
4. Preserve raw GPC/GTC/MEAG/SAV codes. Verify mappings from an official legend or public owner record. Unknown owners remain unknown; never prefix all rows GPC because the PDF came from Georgia Power.
5. Link revisions by native ID and owner, then review name/voltage/type continuity. Never overwrite the old record. Inspect the older DESC `0139 M,N` page 3 and newer page 2 before presenting their date change; both milestones are historical on September 26, 2026.
6. Deliver approved page manifest to Gemini, reviewed reference rows to QA and owner mappings to geo/lead. Track unresolved sources separately so coverage is honest.

## Output and checks
Source manifest, page allowlist, owner mapping evidence, revision links and coverage ledger. All featured records have a traceable approved page. The newer DESC `6809 G` card is a research lead until fully reviewed. Source freshness and permission are separate decisions.
