# F11 Pair page: evidence + coordination card

## Plan
1. `/pair/[id]` page, using `getPair`:
   - **Header:** both projects, utility badges, distance (2 dp), "in service N days apart", band, review state.
   - **Evidence drawer per project:** original name, native id, raw owner code + mapping citation, each endpoint (accepted location with its OSM link and evidence; rejected candidates collapsed), center basis (two / one endpoint), source document and page (DESC pages link to the public PDF `#page=N`; Georgia shows the page number only, per D2), raw date text + precision, version changes. Unknowns read "Not published" or "Needs review".
   - **Coordination card:** deterministic facts, then the Gemini brief (supported facts with their fact ids, possible shared activities, questions, limitations), the model id and generated time. If there's no passed brief: "Brief unavailable".
   - A link to `/impact?pair=<id>` (F17's route; it's a placeholder until F17 lands).
2. `GET /api/export?type=matches|projects&view=`: a CSV with source and uncertainty columns. Prefix any cell starting with `= + - @` with `'`. Limit 5000 rows. It reads through the same active dataset (a server helper under `web/app/api/export/`).
3. **Print:** a "Print card" button using `window.print()` and `@media print` CSS for a one-page card with citations. No PDF library.
4. **Source peek (issue #123):** hovering or keyboard-focusing a citation shows, after about 300 ms, a small card with the
   source title, the stored verbatim quote when one exists (never generated), and "Open page N ↗" only for linkable
   DESC filings (Georgia stays page-number only, D2). CSS only, hover-capable devices only, hidden in print.

## Requirements
- Every number shown has its source visible or one click away.
- Never label a pair "reviewed" unless `review_state` is `confirmed`.

## Validation
- lint, typecheck and build. Fixture-mode screenshots of `/pair/<OVL_2 id>` at 1440 and 390 px, plus a print preview screenshot.
- `curl` the CSV in fixture/dev mode: headers are correct, and the injection-prefix test passes (add a tiny unit test if F00 provided a web test runner; otherwise, a check in the PR body).

## Defaults
- Brief layout: facts first, AI text second, clearly labeled "Generated by Gemini <model> at <time>".
