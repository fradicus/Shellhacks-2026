# F11 decisions (evidence drawer + coordination card)

1. **CSV injection guard applies to text cells, not numbers.** The spec says to prefix any cell starting with
   `= + - @`. Numbers are written as numbers: a negative longitude (`-81.2`) is data, not a formula, and prefixing it
   would corrupt every coordinate column. Text cells starting with `= + - @`, tab or CR get a leading `'`.
   Check: `node web/app/api/export/csv.check.mjs` (plain JS because the frozen tsconfig rejects `.ts` import paths and
   there's no web test runner).
2. **Citations.** DESC values link to the public PDF at `#page=N` only when the source is `public` and has a `url`.
   Georgia shows the page number only (D2). Labels are short ("DESC filing 2025-2029, p. 2"), with the full title on
   hover and printed next to links in print mode.
3. **"Values as filed"** shows only the fields the parser recorded evidence for (`field_evidence`), each with its page
   and the verbatim quote behind a disclosure. Nothing is shown without its source.
4. **Brief.** Only a `passed` brief is shown (the API and fixture layer already filter). Facts first, AI second, labelled
   "Generated by Gemini <model> at <time> · prompt <version>". Fact ids render as chips; hovering shows the fact input.
   No brief → "Brief unavailable".
5. **Export reads the same active dataset** via `web/lib/server` (the F06 query helpers) in API mode, and the fixture
   files through `lib/data.ts` in fixture mode. Limit 5000 rows. Unavailable → 503 JSON, like the API.
6. **Layout test.** The golden fixture has no brief or field evidence, so both were checked with a throwaway fixture
   directory (real F01 record for `DESC:0139 M,N` from PR #5 plus a synthetic brief whose text reads "LAYOUT TEST").
   That data was never committed.
