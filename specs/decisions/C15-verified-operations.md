## Trust rules

Every accepted source records publisher, exact URL, vintage, retrieval time, source/member hashes or actual partial-read identity, parser/model version, row/page/pixel locator and upstream lineage. Syntax/schema validation, source fidelity and independent corroboration are different checks. Conflicting same-subject/same-field/same-semantics/same-vintage claims are quarantined; different vintages remain separate. Preserve rejected claims for review, exclude them from operational/model inputs. Never use vote counts over copied webpages as confidence. A first-party provider may supply attributed primary observations; do not label them independently corroborated without another independent observation of the same fact.

Source timestamps and requested location/time/vehicle bind every operational result. Stale data may be shown as historical evidence, but cannot support a current recommendation. Provider coverage and uncertainties remain visible. No unconditional `safe`, `approved`, `all clear`, or promised savings label is permitted.

## Module and API contracts

F33 owns `pipeline/verified`, `data/verified`, `web/lib/verified`, `web/app/api/verified` and its tests. Versioned outputs are `sources`, `utilities`, `utility-activities`, `service-territory`, `assertions`, `quarantine`, `coverage`, `manifest`. Record files use `{schema_version,dataset,generated_at,records}`; coverage/manifest are objects. EIA utility IDs are string identifiers scoped by vintage. `GET /api/verified` supports strict bounded `state`, `county`, `q`, `page`, `limit`; `GET /api/verified/coverage` returns counts, source vintages and unresolved/conflicting denominators. State is two-digit state FIPS; county is five-digit county GEOID and must belong to the selected state. `q` searches utility ID/name, maximum 120 characters; page starts at 1; limit is 1–100 with default 25. List response is `{available,reason,dataset,generated_at,filters,total,page,limit,records}`, with records `{id,eia_utility_id,data_year,name,state_fips:string[],county_geoids:string[],source_ids:string[],validation_status,limitations:string[]}`. Public list responses omit raw workbook rows. `generated_at` is an explicit recorded build input (not wall-clock generation during replay) and excluded from dataset/content hashes; replay fixes this input. A missing artifact returns unavailable, not sample rows.

F34 owns `pipeline/environment`, `data/environment`, `web/lib/operations`, `web/app/api/operations` and its tests. Export Zod/request/response types from `web/lib/operations/contracts.ts`. Its independent result envelope is `{schema_version,provider,status,request_hash,retrieved_at,source_updated_at,valid_from,valid_to,source_url,source_version,evidence_hash,coverage:{requested,completed,failed,truncated},data,limitations}`. Status is `available|partial|stale|unavailable|out_of_coverage|not_configured|deferred`. Hashes identify only bytes actually read. Keep null data and the reason on failure.

- `GET /api/operations/reference`: supported providers, readiness (no credentials), supported jurisdictions, AEF years actually available, explicit refresh policy, attribution and request enums.
- `GET /api/operations/site?lat=...&lon=...&year=...`: independent `{weather,soil,aef,roadwork}` envelopes plus request location. Reject malformed/nonfinite/duplicate/unknown query parameters. Every provider uses fixed approved hosts and bounded responses/time/retries. No arbitrary proxy URL.
- `POST /api/operations/route`: `{origin:{lat,lon},destination:{lat,lon},departure_at,truck:{height_m,width_m,length_m,gross_weight_kg,axle_count,trailers:{length_m:number}[],hazmat:string[]}}`. No vehicle defaults; require finite positive dimensions/weight, integer axles, an explicit trailer list (empty means no trailers) and an explicit hazmat list. Require positive bounded per-trailer lengths; total dimensions, gross weight and axles include all trailers/load. Map trailers to Google `trailerInfo[].lengthMm`, omitting `trailerInfo` only for an explicit empty list. Return `{route,weather,roadwork,aef,limitations}` envelopes, original request and status. Return only a textual attributed route summary (distance, travel seconds/ETA, ignored-restriction flag and warnings); omit route tokens, geometry and raw response. No route alternatives are promised in this version. Missing LVR provisioning/key means no route. Unsupported hazmat classes are rejected. Each weather/work-zone result describes sampled scope/gaps; annual AEF is a separate required environmental check, never a current-condition substitute. Missing AEF must be visible and precludes claiming the full assessment complete.

F35 owns `pipeline/outcomes`, `web/lib/outcomes`, `web/app/api/outcomes` and tests. Raw authorized imports and model artifacts stay outside tracked directories by default. Versioned strict schemas define source manifests, jobs, append-only planned/actual events, review decisions and model artifacts. `GET /api/outcomes/status` exposes readiness, eligibility counts and evaluation (no private rows). `POST /api/outcomes/predict` accepts `{job_type,company_id,region,as_of,planned_duration_days?,planned_duration_confirmed_at_as_of?}`. Response is `{status:predicted|insufficient_evidence|unavailable|invalid,reason,prediction:null|{duration_days:{lower,median,upper},delay_probability:number|null},support,evaluation,model_version,limitations}`. `delay_probability` means the evaluated empirical probability that actual construction duration exceeds the caller-supplied positive `planned_duration_days`; it is null without that baseline or without a passing separate probability evaluation. Echo the request baseline and `as_of`, label the baseline user-provided and require `planned_duration_confirmed_at_as_of: true` whenever the optional baseline is supplied. Echo that confirmation; it records the caller assertion, not independent verification. Historical probability evaluation needs actual durations and frozen pre-outcome planned duration baselines; this is not a prediction of in-service milestone slippage. No fallback fixture or invented cohort. Exact feature names/validation and metric definitions are recorded in the F35 spec/schema. F36 shows the abstention reason rather than zeros.

F36 depends on completed F33/F34/F35 and their exported validated payload types; it does not infer provider data shapes from this envelope. F33/F34/F35 are independent and may implement concurrently. F36 owns `/operations`, its components and UI tests. API types come from the owning modules. Server-only credentials stay outside browser code. Keep controls simple: explicit worksite/origin, departure, truck facts, optional job/cohort facts. Results separate annual/reference context, current observed/forecast disruptions, route restrictions and estimated duration. Show source times and validation reasons, provider-specific retry and refresh; suspend polling when hidden/unmounted. Poll no faster than declared upstream/local limits. Do not present Google routing on the existing MapLibre basemap; this page uses an attributed route-only panel until a separately configured Google map is approved.

The technical lead adds navigation/tracing/CI in a separate shared integration commit after the route/artifacts exist, preserving other machines' `/search` and CI work. Browser tests use the existing GitHub CI server. The previous local server launch approval rejection is not bypassed.

## Current primary-source findings (checked 2026-09-26)

- [EIA-861](https://www.eia.gov/electricity/data/eia861/) labels 2025 early release as unvalidated. Start with reviewed 2024 final. [EIA territory FAQ](https://www.eia.gov/TOOLS/FAQS/faq.php?id=448&t=5) describes distribution-equipment counties, not exclusive boundaries.
- [AEF catalog](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_SATELLITE_EMBEDDING_V1_ANNUAL) describes annual 10m/64-band embeddings. [GCS specification](https://developers.google.com/earth-engine/guides/aef_on_gcs_readme) has newer years than the catalog: inspect pinned actual assets. Decode signed byte values with the documented nonlinear formula and reject nodata. Attribution is mandatory.
- [Google LVR](https://developers.google.com/maps/documentation/routes/lvr) is provisioned for limited customers and has limited coverage. [Request guide](https://developers.google.com/maps/documentation/routes/lvr-routes-etas) exposes TRUCK dimensions/weight/axles and `routeRestrictionsPartiallyIgnored`; absence of that flag is not a safety guarantee. [Display policy](https://developers.google.com/maps/documentation/routes/policies) and [service terms](https://cloud.google.com/maps-platform/terms/maps-service-terms) restrict non-Google map use and retention. No persistent raw Google route cache or committed responses.
- [NWS API](https://www.weather.gov/documentation/services-web-api) provides point/grid forecasts and alerts; [alert guidance](https://www.weather.gov/documentation/services-web-alerts) discourages excessive polling. Point samples do not prove corridor-wide coverage.
- [USDA SDA](https://sdmdataaccess.nrcs.usda.gov/WebServiceHelp.aspx) and [SSURGO](https://www.nrcs.usda.gov/resources/data-and-reports/soil-survey-geographic-database-ssurgo) provide survey context. Preserve components, units/depths, vintage and missing values.
- [USDOT registry](https://data.transportation.gov/resource/69qe-yiui.json) identifies WZDx feeds; verify the actual selected feed before marking it available. No nationwide all-clear from incomplete feed coverage.
- Public [ISO-NE outcomes](https://www.iso-ne.com/static-assets/documents/100031/er13-193_annual_info_filing_transmission_projects.pdf) and [PJM outcomes](https://www.pjm.com/-/media/DotCom/documents/ferc/filings/2026/20260130-er13-198-000.pdf) contain milestone history but generally no actual construction start. They are not substitutes for Dakota's authorized completed-job records.

Undo by removing the additive route/modules and optional extra. Existing planner/national data and MongoDB writers remain unchanged. Deliverables may be implemented and verified offline; live access, actual historical records and measured accuracy remain explicitly unclaimed until evidenced.
