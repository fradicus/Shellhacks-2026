# F48 national candidate backend

- Added a conservative spatial generator, cited owner-alias ledger and provisional pair coverage report.
- Added the dataset-pinned `/api/national-pairs` read API: scope, 50-row pages, shared selection, explicit failures.
- Five Python tests cover exact boundaries, brute-force equivalence, aliases, shared owners, scope and date precision; API tests cover paging and dataset/query failures.
- Initial measured snapshot: 1,240 pairs from 2,019 eligible projects, 0.082 s generation excluding snapshot loading.
- F30 publication hookup and F19 scoped list remain separate C48 integration parts; this backend alone does not publish or display pairs.
