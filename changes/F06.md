# F06 Atlas loader + read API

- Shipped: `python -m load` validates every record under the loadable `data/` folders, joins locations into projects (center via `core.center`, GeoJSON `geo`), writes under a dataset id (git sha), flips `meta.active` only when everything validated, keeps active + previous, and writes a `runs` doc either way. Idempotent. 8 mongomock tests.
- Shipped: `/api/projects` (bbox → `$geoWithin` on a `2dsphere` index), `/api/matches`, `/api/pairs/[id]`, `/api/versions`, `/api/coverage`, `/api/extraction`: strict zod params (unknown → 400), active dataset only, 503 `{unavailable: true}` on DB failure, no write routes.
- Verified end to end against a local MongoDB 8: loader → Mongo → API → `data.ts` → home page (screenshot in PR), plus 400/404/503 cases.
- Known gaps: not yet run against Atlas; secrets aren't configured (see the `human-morning` issue). Loader skips with a warning without `MONGODB_URI_RW`.
